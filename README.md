# SPR-Analysis



A mvp lab based project for spr analysis with gui interface.







Run the following in command , provided u have git: (venv can have slight problem on powershell, if u do so feel free to ignore command line 3 and 4)



git clone https://github.com/BillerBoom/SPR-Analysis.git

cd SPR-Analysis

python -m venv .venv

.venv\\Scripts\\activate

pip install -r requirements.txt

python -m sources.main
